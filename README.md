A one-line entry for the "One Line, One Laugh" bounty: a single funny line on any subject. The line takes a smart fridge that oversteps and emails its owner a diet plan — and the owner answers with petty revenge: unplug the fridge and eat ice cream out of spite. The program validates the line (at most 140 characters, ASCII, single line) and writes it to `entry.txt`.

## Run it

```sh
python3 main.py
```
